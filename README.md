# Modern Webpage

A modern beginner-friendly web development project built using HTML, CSS, and JavaScript.

This project demonstrates the fundamentals of frontend web development including webpage structure, styling, responsive layouts, and interactive JavaScript functionality.

---

## 🚀 Features

- Modern Navigation Bar
- Hero Section
- Responsive Card Layout
- Progress Bars
- Contact Form
- Dark Mode Toggle
- Interactive Buttons
- Hover Effects & Animations
- Clean UI Design

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
